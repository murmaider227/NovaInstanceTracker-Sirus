# Nova Instance Tracker для Sirus

Адаптированная версия Nova Instance Tracker для русскоязычного клиента World of Warcraft Sirus на базе WotLK 3.3.5a.

Автор адаптации: **murmaider227**.

## Возможности

- регистрация входов и выходов из подземелий;
- продолжение того же захода после выхода без сброса подземелья;
- подсчёт убитых мобов, включая серых мобов без опыта;
- подсчёт полученного опыта, среднего опыта за моб и опыта в час;
- расчёт количества заходов на уровень и до следующего уровня;
- учёт золота, репутации, чести и очков арены;
- отображение времени прохождения без учёта времени, проведённого снаружи;
- контроль ограничений на входы за час и за сутки;
- журнал подземелий и статистика персонажей.

## Установка

1. Скачайте репозиторий архивом.
2. Переименуйте папку в `NovaInstanceTracker`, если она называется иначе.
3. Поместите её в `World of Warcraft Sirus/Interface/AddOns/`.
4. Запустите игру или выполните `/reload`.

Настройки открываются командой `/nit`.

## Совместимость

Версия предназначена для Sirus и учитывает отличия его API и локализованных игровых сообщений от обычного клиента WotLK Classic. На других серверах работа не гарантируется.

Интерфейс, подсказки, сообщения чата, статистика, названия подземелий и резервные названия отслеживаемых предметов полностью переведены на русский язык.

## Основа проекта

Адаптация основана на оригинальном аддоне [Nova Instance Tracker](https://www.curseforge.com/wow/addons/nova-instance-tracker) от Novaspark-Arugal OCE. Изменения для Sirus и дальнейшая поддержка этой версии выполняются murmaider227.
